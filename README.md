# A2A 接口契约（跨仓库共享）

这里放 `ai-sql-agent`（服务端）与 `ai-helpdesk`（客户端）之间的接口契约。

放在两个仓库之外，是因为它**同时**约束两边：留在任何一侧都会变成
"一方的文档"，而契约变更必须是双边事件。

| 文件 | 说明 |
| --- | --- |
| `a2a-streaming-contract.md` | `message/stream` 流式契约 |

## 规矩

- 契约变更 = 双边事件。任何一侧不得单方面修改后直接实现。
- 两个仓库都不再各存一份副本，只引用这里，避免副本漂移。
- 文档顶部的状态行（草案 / 已定稿 vX.Y）就是当前生效版本。
